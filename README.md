# РемГазель — SEO-лендинг автосервиса

Готовый одностраничный PHP-сайт для автосервиса «РемГазель» в Мытищах. Внутри: адаптивная вёрстка, SEO-разметка, формы заявок, сохранение лидов в CSV, email-уведомления и опциональная отправка в Telegram.

## Как запустить локально

Нужен PHP 8.1+.

```bash
php -S localhost:8000
```

После запуска откройте `http://localhost:8000`.

## Куда вставить email

Откройте `config.php` и замените:

```php
'email_to' => 'mail@example.com',
'email_from' => 'no-reply@remgazel.ru',
```

На боевом хостинге функция `mail()` должна быть включена. Если письмо не уходит, проверьте настройки отправки почты у хостинг-провайдера и файл `storage/error.log`.

## Как подключить Telegram-уведомления

Создайте бота через BotFather, получите токен и chat ID. На хостинге задайте переменные окружения:

```bash
TELEGRAM_BOT_TOKEN=123456:ABC...
TELEGRAM_CHAT_ID=123456789
```

Если переменные не заданы, сайт просто пропустит отправку в Telegram и продолжит сохранять заявки в CSV.

## Где менять телефон, адрес и график

Все основные данные лежат в `config.php`:

```php
'phone' => '+7 (903) 296-06-93',
'phone_href' => '+79032960693',
'address' => 'Московская область, Мытищи, проезд № 4530',
'hours' => 'Ежедневно 08:00–22:00',
```

Там же меняются `site.url`, Open Graph URL и базовая микроразметка.

## Как заменить карту

Сейчас в блоке контактов стоит аккуратный placeholder с кнопкой на Яндекс Карты. Чтобы поставить реальную карту, замените блок `.map-placeholder` в `index.php` на embed-код Яндекс Карт и сохраните рядом кнопку «Построить маршрут».

## Как загрузить сайт на хостинг

1. Загрузите все файлы в корень сайта на PHP-хостинге.
2. Проверьте, что доступны папки `api`, `assets`, `storage`.
3. Убедитесь, что PHP может писать в папку `storage`.
4. Если используете собственный домен, замените `site.url` в `config.php`, `robots.txt` и `sitemap.xml`.
5. Укажите рабочий email в `config.php`.
6. При необходимости задайте Telegram-переменные окружения.

## Как проверить отправку заявки

1. Откройте сайт.
2. Заполните телефон и описание проблемы в любой форме.
3. После отправки должно появиться сообщение: «Заявка отправлена. Мастер свяжется с вами в ближайшее время».
4. Проверьте, что новая строка появилась в `storage/leads.csv`.
5. Если настроен email или Telegram, проверьте уведомление.
6. При ошибке смотрите `storage/error.log`.

## Файлы проекта

- `index.php` — HTML/PHP-лендинг, SEO, JSON-LD, формы.
- `assets/css/styles.css` — адаптивный UI в стиле сервисной панели.
- `assets/js/main.js` — меню, анимации, UTM и отправка заявок через `fetch`.
- `api/lead.php` — backend обработки заявок.
- `config.php` — настройки сайта, контактов и уведомлений.
- `storage/leads.csv` — сохранённые заявки.
- `storage/error.log` — технические ошибки.
- `robots.txt` и `sitemap.xml` — базовые SEO-файлы.
